# Seabil Backup and Export

Seabil provides user-facing backup and export tools for supported data.

## Good practices

- Keep backup copies in trusted locations
- Keep more than one copy if the data is important
- Review exported CSV data before sharing
- Treat subscription records as potentially sensitive financial information

## Scope

This public repository does not document internal database structure, storage schemas or implementation details.
