# Seabil Troubleshooting

## A subscription total looks wrong

- Recheck the recurring amount
- Recheck the billing interval
- Confirm the currency you intended to use
- Review edited subscription details

## Import or export issue

- Confirm the file is complete
- Confirm the format is supported
- Keep the original file until the import succeeds

## Widget issue

Confirm that Android has not restricted the app and that the widget is still placed on the home screen.
