# Getting Started with Seabil

Seabil helps you track subscriptions and recurring costs on Android.

## Typical workflow

1. Add a subscription
2. Enter the recurring price and billing interval
3. Add important notes or dates
4. Review upcoming recurring costs
5. Use available backup or export features when needed

## Supported public features

- Subscription tracking
- Recurring-cost overview
- Smart Paste where supported
- Backup and restore
- CSV support where available
- Widget support

## Access model

Seabil includes a free tier with a limited number of subscriptions and a Lifetime option for expanded use.
